# Academic Pressure, Mental Health & Students' Intent to Quit

This repository contains my undergraduate thesis:

**"Applying Data Analytical Methods to Explore the Impacts of Academic Pressure on Mental Health and Students' Intent to Quit."**

The project analyzes survey data to investigate how academic pressure and related factors affect students' mental health and their intention to quit.

The study applies data analysis and machine learning techniques including classification models, PCA, K-Means clustering, OLS regression, correlation analysis, and Information Gain.

## Technologies

Python, Pandas, NumPy, Scikit-learn, XGBoost, Statsmodels, Matplotlib, Seaborn
